## How to use this note

The knowledge note cites in short form -- **(Wassmer et al. 2025)**. This
note expands every key into a full reference. Chanakya fetches both when the
flow runs: the knowledge for the analysis, this note for the references it
ships with the answer.

**Vintage** is the date of the publication or data, not the date it was read.

**Verification** -- `read`: the full text was read. `passages`: the full text
was searched for the topic, and every passage used was read in its context;
the rest was not read. `abstract`: only the abstract was available.
